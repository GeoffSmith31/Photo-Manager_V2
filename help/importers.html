Photo Manager Help

Available Importers

Importers are standalone applications that obtain photographs and associated information from different sources and prepare them as projects for Photo Manager.

The following Importers are currently available. Each has its own documentation, installation instructions and release information.

Filesystem Importer

The Filesystem Importer creates Photo Manager projects from photographs stored in local directories.

It examines available image metadata and directory organisation to propose descriptive information for photographs. This can include Event, Year, Location and additional descriptive information.
