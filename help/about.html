About Photo Manager

Photo Manager is an application for managing photo projects, recording information about photographs, and saving that information in the photographs' metadata.

How to Contribute

Developing Importers

Photo Manager supports different sources of photographs through standalone Importer applications. Developers are welcome to create Importers to support additional sources.

The following technical documents provide guidance and specifications for developers:

  • Importer Developer's Handbook (PDF) – Practical guidance for developing standalone Importers.
  • Photo Manager Project JSON Reference (PDF) – The specification defining the structure and contents of Photo Manager projects.
  • Photo Manager Core Design Specification (Draft) – Describes the application architecture and project management.

Additional technical documentation and editable document versions are available in the Photo Manager GitHub documentation repository.

Available Importers

Importers are separate applications that allow Photo Manager to obtain photographs and associated information from different sources.

See the Available Importers page for information, documentation and download links for Importers that are available for use with Photo Manager.

Supporting the Project

Photo Manager is an open-source project. If you find it useful, you can help support its continued development through a financial contribution.
