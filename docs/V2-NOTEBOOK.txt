V2 Ideas

New name for the application

V2 Design: Develop an Importer SDK Specification defining the Core API exposed to importers. The SDK will encapsulate workspace creation, project management and photo management, allowing importers to operate without knowledge of project storage or filesystem layout.

Architecture
------------
- Remove duplicate current_index logic.
- Project owns navigation.
- Eliminate globals.
- Better backend state ownership.
- Navigation endpoints should always update editor state through a single synchronization function.
- Make project.json the single source of truth for photo metadata.
- Apply metadata inheritance during Save by updating Info for subsequent incomplete photos in the same moment and Location for incomplete photos with the same location_key.
- Render the editor directly from photo values stored in project.json rather than the in-memory defaults cache.
- Restrict the moment defaults cache to assisting inheritance only; it should not determine what the editor displays.
- Validate and sanitise the user-entered Event Name before using it as workspace.image_folder. Preserve the original event name for display purposes. Generate a filesystem-safe directory name that is portable across Linux, Windows and macOS.
