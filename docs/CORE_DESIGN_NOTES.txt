## UI-001 - ACTION_REQUIRED Presentation

Status: Proposed

Summary

ACTION_REQUIRED messages shall be acknowledged by the user before being
dismissed.

Notes

Acknowledgement confirms that the user has seen the instruction. It does
not indicate that the requested action has been completed.

The Importer remains responsible for detecting completion of the
requested action.

Design Notes: 

The communications interfaces are intentionally asynchronous. Commands issued using IMPORTER-001 do not return result codes. Completion of a command is reported by the Importer using the existing CORE-004 communications interface where appropriate.

Asset registration is a distinct phase that SHALL complete before asset acquisition begins.

Photo Manager shall minimise complexity for two audiences: end users and extension developers.

STATE MACHINES

The Photo Manager has two independent but related state machines. The Orchestrator State represents the application's current operational state. The Workflow Stage represents the project's progress through the overall workflow. Both are controlled by the Orchestrator. A change in one does not necessarily imply an immediate change in the other.
